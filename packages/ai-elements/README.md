# `@sealwax/zcode-ui-ai-elements`

Standalone AI chat / agent UI primitives extracted from ZCode `packages/ui` (vercel/ai-elements lineage, Apache-2.0).

Depends on `@sealwax/zcode-ui-core`. Optional peers: `ai`, `shiki`, `motion`, `nanoid`, `use-stick-to-bottom`, `ansi-to-react`, `@rive-app/react-webgl2`.

```tsx
import { Sources, SourcesTrigger, SourcesContent, Source } from "@sealwax/zcode-ui-ai-elements/sources";
import { CodeBlock, CodeBlockCopyButton } from "@sealwax/zcode-ui-ai-elements/code-block";
```

See repo root `docs/API.md` for the full 1.0 export surface.
