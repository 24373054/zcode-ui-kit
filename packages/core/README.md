# @zcode-ui/core

Standalone React components extracted from ZCode `packages/ui`.

```sh
pnpm build      # → dist/ (ESM + .d.ts)
pnpm typecheck
```

Import from the package root or per-component entry (`@zcode-ui/core/button`).
Optional peers: `recharts` (chart), `motion` (flip-metric-value, shimmer).
