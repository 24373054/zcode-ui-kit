# `@zcode-ui/core`

Standalone shadcn-style React components extracted from ZCode `packages/ui`.

As of **1.0.0**, lightweight AI elements (`shimmer` / `suggestion` / `snippet`) live in `@zcode-ui/ai-elements`.

```tsx
import { Button } from "@zcode-ui/core/button";
import { cn } from "@zcode-ui/core/utils";
```
