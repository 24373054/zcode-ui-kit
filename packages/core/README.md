# `@sealwax/zcode-ui-core`

Standalone shadcn-style React components extracted from ZCode `packages/ui`.

As of **1.0.0**, lightweight AI elements (`shimmer` / `suggestion` / `snippet`) live in `@sealwax/zcode-ui-ai-elements`.

```tsx
import { Button } from "@sealwax/zcode-ui-core/button";
import { cn } from "@sealwax/zcode-ui-core/utils";
```
